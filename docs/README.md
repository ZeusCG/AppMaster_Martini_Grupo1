# Evidencia del proyecto

Carpeta de evidencias del entregable. Contenido esperado:

- `capturas/` – imágenes de:
  - tablero **Trello** con las tarjetas y su dueño,
  - **reporte de cobertura** JaCoCo (`app/build/reports/jacoco/jacocoTestReport/html/index.html`),
  - **APK firmado** (`release/app-release.apk`) y **llave** (`release/appmaster.jks`),
  - verificación de firma con `apksigner verify --print-certs`.
- `indicacion-docente.md` – registro de la indicación del docente sobre el backend.

Las capturas deben agregarse antes de la entrega (son evidencia, no se generan solas).
